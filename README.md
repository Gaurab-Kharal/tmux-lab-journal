# tmux Lab Journal

My practical learning notes and personal configuration for **tmux** on Debian Linux.

This repository is part of my Linux and terminal learning journey.

## What is tmux?

tmux is a terminal multiplexer.

It allows multiple terminal environments to exist inside a single terminal window and, more importantly, allows terminal sessions to continue running independently of the terminal emulator.

My basic environment:

```text
Debian
└── Konsole
    └── tmux
        ├── Session
        │   ├── Window
        │   │   ├── Pane
        │   │   └── Pane
        │   └── Window
        └── ...
```
